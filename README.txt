===================================================
 PROYECTO: UNIVERSO INTERACTIVO HOT WHEELS / MOTOS
===================================================

ESTRUCTURA DEL PROYECTO:
------------------------
proyecto-hotwheels/
├── index.html          # Estructura principal de la página
├── css/
│   └── style.css       # Estilos visuales y luces neon
├── js/
│   └── main.js        # Lógica del Universo 3D con Three.js
└── assets/
    └── images/         # Carpeta para colocar tus propias imágenes PNG de motos

CÓMO ABRIR EN VISUAL STUDIO CODE:
---------------------------------
1. Descomprime la carpeta 'proyecto-hotwheels.zip'.
2. Abre Visual Studio Code.
3. Ve a 'Archivo' > 'Abrir carpeta...' y selecciona la carpeta 'proyecto-hotwheels'.
4. Abre el archivo 'index.html' y haz clic derecho -> 'Open with Live Server' (si tienes la extensión) o simplemente haz doble clic en 'index.html' en tu explorador de archivos.
